# 🛡️ CyberGuard AI – Phishing Detector

A beginner-level Python project for detecting suspicious patterns in messages and URLs.

## Features

- Detects suspicious words
- Detects HTTP/HTTPS links
- Gives LOW, MEDIUM or HIGH risk
- Shows reasons for the result
- Provides basic safety advice

## Technology Used

- Python
- Regular Expressions
- String Processing

## How to Run

1. Install Python or Pydroid 3.
2. Open `cyberguard.py`.
3. Run the program.
4. Enter a message or URL.
5. Check the result.

## Example

Input:

Congratulations! You are a winner. Claim your free prize: https://example.com

Output:

HIGH RISK

## Important Note

This is an educational prototype.
The current version uses rule-based detection and is not a professional
or fully AI-powered phishing detection system.
